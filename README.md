## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `meme.png` and `POST.json` into `out/`. The run is deterministic: same bytes every time.
